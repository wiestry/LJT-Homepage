# LJT-Homepage

Personal academic homepage of **Junteng Liu**, built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) (a [Jekyll](https://jekyllrb.com/) theme based on [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)).

- First-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.
- Research interests: LLM Reasoning and Reinforcement Learning, Hallucination in Vision-Language Models, LLM truthfulness and Interpretability.

## Structure

- `_pages/about.md` — the About / home page (bio, education, research experience, publications, skills, awards, contact).
- `_pages/publications.html` — the Publications subpage.
- `_publications/` — individual publication entries rendered on the Publications subpage.
- `_data/navigation.yml` — header navigation (About, Publications).
- `_config.yml` — site configuration (title, author, sidebar links).
